# ربات سلف (aiogram 3 + PostgreSQL + Redis)

## ساختار
- `app/texts.py` همه‌ی متن‌ها (لحن رو از اینجا عوض کن)
- `app/config.py` تنظیمات و ثابت‌ها (مهلت پرداخت، درصد پورسانت و ...)
- `app/services/` منطق پول، اشتراک و پرداخت (اتمیک و ضد ریس‌کاندیشن)
- `app/handlers/` دکمه‌ها و دستورها
- `app/db/models.py` جدول‌ها

## راه‌اندازی روی Railway
1. این پوشه رو توی یک ریپوی **خصوصی** GitHub بذار.
2. توی Railway: **New → GitHub Repo** و همین ریپو رو انتخاب کن.
3. توی همون پروژه **PostgreSQL** و **Redis** رو اضافه کن (اگه قبلاً نکردی).
4. توی سرویس ربات، بخش **Variables**:

| نام | مقدار |
|---|---|
| `BOT_TOKEN` | توکن BotFather |
| `ADMIN_IDS` | آیدی عددی ادمین (چندتا؟ با کاما جدا کن) |
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
| `REDIS_URL` | `${{Redis.REDIS_URL}}` |
| `WEBHOOK_SECRET` | متن تصادفی 32 تا 64 کاراکتری (فقط حروف انگلیسی، عدد، `_` و `-`) |
| `ENCRYPTION_SECRET` | یک متن تصادفی بلند دیگه، حداقل 32 کاراکتر. **یه نسخه‌اش رو جای امن نگه دار** |
| `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` | از my.telegram.org (API development tools) با یک حساب خودت بگیر؛ برای اتصال حساب کاربرها لازمه |
| `CARD_NUMBER` | شماره کارت |
| `CARD_HOLDER` | نام صاحب کارت |
| `SUPPORT_USERNAME` | (اختیاری) یوزرنیم پشتیبانی |

اگه اسم سرویس‌های دیتابیس و ردیس‌ت فرق داره، همون اسم رو جای `Postgres` و `Redis` بنویس.

5. سرویس ربات → **Settings → Networking → Generate Domain**. بعدش یک‌بار **Redeploy** کن.
6. ادمین‌ها باید یک‌بار به ربات `/start` بزنن تا رسیدها بهشون برسه.
7. برای دیدن آمار، ادمین `/admin` می‌فرسته.

## نکته‌های مهم
- دیتابیس: فعلاً جدول‌ها موقع اجرا ساخته می‌شن. قبل از شروع فروش واقعی، سیستم مایگریشن (Alembic) اضافه می‌کنیم تا تغییرات بعدی امن باشن.
- `ENCRYPTION_SECRET` رو هرگز عوض نکن، وگرنه سشن‌های ذخیره‌شده خوانا نمی‌مونن.
- توکن و کلیدها فقط توی Variables؛ هیچ‌وقت توی کد یا چت.

- اتصال حساب‌ها توی حافظه‌ی همین پردازش انجام می‌شه؛ ربات رو روی **یک نسخه** (1 replica) اجرا کن.
- `TELEGRAM_API_HASH` و `ENCRYPTION_SECRET` مثل رمز بانکی‌ان؛ هیچ‌جا بیرون از Variables نذارشون.

## تبچی (موتور سلف)
- موتور داخل همین پردازش اجرا می‌شه (`RUN_WORKER=true` پیش‌فرضه). هر ۱۵ ثانیه از دیتابیس می‌خونه کدوم حساب‌ها باید روشن باشن (متصل + سلف روشن + اشتراک فعال).
- دستورها رو کاربر از **حساب خودش** می‌نویسه: «تنظیم پشتیبان» (کانال خصوصی)، «تنظیم بنر» (ریپلای روی بنر داخل گروه)، «تنظیم زمان بنر "2 دقیقه"»، «تبچی روشن»، «تبچی خاموش»، «حذف بنر».
- محدودیت‌ها رو از `app/config.py` عوض کن: کمترین بازه (`MIN_BANNER_INTERVAL`)، حداکثر گروه فعال (`MAX_ACTIVE_BANNERS`) و فاصله‌ی دو ارسال (`ACCOUNT_MIN_GAP_SECONDS`).
